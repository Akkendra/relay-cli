WHAT RELAY DOES

Small tasks stay cheap. Risky ones get a careful look.

01

Routes each task to the right model

Free local scoring picks a small, medium, or large model, and borderline tasks get a second opinion. Near a plan limit, Relay steps down a tier and tells you why.

02

Reviews what actually changed

Claude reviews with no tools, sees the files your change imports, and must quote the lines it's talking about. Unverifiable findings are flagged, not acted on.

03

Asks before anything runs

Tests run only after a yes. Codex stays in its sandbox and can't escalate. Likely secrets stop a review before anything is sent.

04

Leaves the decision with you

The best outcome is "needs your decision". Relay never commits, pushes, or deploys, and /undo puts a task's changes back.

INSTALL

Two signed-in CLIs and Node 22.

Relay uses the Codex and Claude Code CLIs you already sign in to with your subscriptions. No API keys.

# once
git clone https://github.com/Akkendra/relay-cli && cd relay-cli
npm install && npm run build:dashboard && npm link

# in any project
relay
relay dashboard   # http://localhost:4318
